# Design System

Load and follow the `design-system` skill.

Host arguments: `$ARGUMENTS`

Use the host arguments as the design brief when present. Otherwise inspect the current workspace and existing design-system artifacts. Reuse confirmed repository facts and ask focused questions about missing product, brand, platform, accessibility, and governance decisions.

Resolve bundled references, examples, and scripts relative to the installed `design-system` skill, not the current workspace. Validate both artifacts and fix every reported error before reporting results.
